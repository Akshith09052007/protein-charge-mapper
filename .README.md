# Protein Sequence Charge Distribution Mapper

## Project Overview
A bioinformatics web application designed to parse protein sequences (FASTA) and plot local pH-dependent charge distributions using dynamic sliding window profiling.

## Features
- **Sequence Validation:** Sanitizes raw inputs and checks against the standard 20 amino acid alphabet.
- **pH-Dependent Charge Math:** Calculates partial charges across different pH levels using Henderson-Hasselbalch equations.
- **Sliding Window Density:** Maps localized charge density across custom window sizes.
- **Interactive Plotting:** Visualizes charge profiles using Plotly and Streamlit.
